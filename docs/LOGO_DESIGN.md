# 公司Logo设计方案

## 设计规范
- 尺寸: 120x120px
- 格式: SVG (矢量，高清)
- 风格: 渐变背景 + 白色首字母
- 圆角: 20px

## 使用方法

1. 将SVG代码保存为 .svg 文件
2. 上传到图床 (如: https://sm.ms)
3. 获取图片URL
4. 更新数据库中公司的 logo 字段

或者使用在线占位服务生成:
https://ui-avatars.com/api/?name=Gate&background=FF6B35&color=fff&size=120&rounded=true&bold=true
